Privacy policy

Local Stack Connector. How data accessed through Google APIs is handled.

Data accessed

The app reads file content from Google Drive and message content from Gmail, using read-only scopes only.

Where the data goes

All data is copied only to software running on hardware the owner personally controls. Nothing is sent to any third-party server or to anyone other than the owner.

Sharing

No data obtained through this app is sold, rented, shared or disclosed to any third party, for advertising or any other purpose.

Retention and deletion

Data is held only in the owner's local storage, for as long as the owner chooses, and can be deleted at any time. Removing the app at Google Account permissions stops all further access immediately.

Google API Services User Data Policy

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent to the developer contact address registered for this application in Google Cloud Console.
